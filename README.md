# PDFNova — Professional Privacy-First PDF Suite

> **Developed by Biren**

A high-performance, privacy-first PDF suite inspired by **iLovePDF.com** and **Smallpdf.com**, featuring **37+ complete tools** running **100% client-side in the browser** (powered by `pdf-lib`, `pdf.js`, `tesseract.js`, and `JSZip`). Zero files are ever uploaded to external servers — ensuring complete privacy, zero latency queues, and unlimited free use.

---

## Complete Feature Matrix (37+ Tools)

### 1. Organize
| Tool | Description |
|---|---|
| **Merge PDF** | Combine multiple PDFs into a single file with custom ordering |
| **Split PDF** | Split by custom ranges (`1-3, 4-6`) or one file per page |
| **Organize PDF** | Visual thumbnail previews to sort, reorder, rotate, and delete pages |
| **Extract Pages** | Pull specific page intervals into a new document |

## Production SEO Architecture

PDFNova is pre-configured and optimized for immediate live production deployment:
- **Semantic HTML5 & Accessibility**: Clean landmarks, ARIA live regions, and responsive meta tags.
- **Rich JSON-LD Structured Data**: `WebApplication` schema, `SoftwareApplication` schema, and `FAQPage` schema.
- **OpenGraph & Twitter Cards**: Complete social media preview metadata.
- **Dynamic On-Page SEO Sections**: Step-by-step how-to guides and FAQs rendered dynamically under every tool on `tool.html`.
- **`sitemap.xml`**: Pre-built XML sitemap listing `index.html` and all 37 tool URLs.
- **`robots.txt`**: Standard crawler directives with sitemap reference.
- **`manifest.json`**: Progressive Web App (PWA) manifest for desktop and mobile installation.
